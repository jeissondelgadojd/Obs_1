# 🇨🇴 Observatorio Socioeconómico Departamental – Colombia

Aplicación Streamlit para análisis socioeconómico a nivel departamental.

## Características

- 35 indicadores (2010-2023)
- Resumen Ejecutivo configurable
- Intento de mapa coroplético real + fallback automático a ranking
- EDA + PCA, VAR, Machine Learning, Simulador
- Título con degradado de color

## Instalación

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

Sube este repositorio a GitHub → https://share.streamlit.io → Main file: `app.py`

## Nota de datos

Panel sintético calibrado. La mayoría de series oficiales departamentales aún no están en API pública limpia.
